# 261020 부천 AI 챗봇 실습 - 스마트 여행 일정 플래너

## 개요
- Groq API (`openai/gpt-oss-20b`)를 활용한 터미널 기반 CLI 대화형 챗봇
- 여행지, 기간, 예산, 선호 스타일에 따른 **맞춤형 여행 일정 및 경비 산출 플래너** 구현

## 주요 기능
- **맞춤형 여행 일정 추천**: 여행 스타일(휴양, 맛집, 액티비티 등)을 고려한 동선 최적화 코스 제공
- **Markdown 표 구조화**: 일자별 동선 및 예상 경비를 표(Table) 형태로 가독성 있게 제시
- **유연한 예외 처리**: 정보가 부족하거나 '추천해줘' 요청 시 대표 가성비 코스 자동 제안
- **실용적인 여행 팁 제공**: 해당 지역 방문 시 유용한 준비물, 환전, 날씨 관련 정보 안내
- **대화 맥락 유지**: 연속적인 질문 및 대화 기록을 기반으로 세부 일정 수정 가능

## 기술 스택
- Python 3.10+
- Groq API (`groq`)
- `python-dotenv`
